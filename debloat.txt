# Xiaomi L65MB-FAEU (Amazon AFTBR92D74, ginzaeu, MediaTek MT5873), Fire OS 8.1.8.5 / Android 11 (SDK 30)
# Tested on that TV. Read it before running remove.sh: comment out (#) anything you use. Batch 4 is the
# original owner's choice of unused apps and casting: edit it for yours.
#
# Never listed here: com.amazon.tv.launcher. It is protected on Fire OS 8 ("Cannot disable a protected
# package") and stays as the system Home; the launcher in launcher/ covers it instead.
#
# Since 2026-11-18 everything is REMOVED FOR USER 0 (pm uninstall -k --user 0): Appstore auto-updates were
# switching disabled packages back on (Luna, Music, Silk, News, ZDF came back that way). The system copy
# stays on the TV, so it is reversible; packages Fire OS won't remove are disabled instead.
# Apply:   ./remove.sh             (or ./remove.sh <batch number>)
# Undo:    ./restore.sh            (reinstalls/re-enables every package in this file)
# Comment out a line to keep that app.
#
# Kept on purpose: Alexa (vizzini, aria, alexa*), AirPlay, whisperplay/whisperlink (phone remote app),
# OTA updates, Live TV + tuner (livetv, mediatek.*, vewd HbbTV, MHEG), HDMI/TIF inputs, keyboard (tv.ime),
# remote/Bluetooth (bluetooth, blepa, fireinputdevices, autopairservice), Appstore (venezia),
# Netflix, YouTube, Prime Video, Disney+, HBO Max, Apple TV, Spotify, NordVPN.
